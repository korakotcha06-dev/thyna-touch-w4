# บ้านสบาย ช็อป · แดชบอร์ดยอดขาย (W3-A / W3-B)

งานคาบ 3 ของเวิร์กช็อป "AI Model, LLM และ Vibe Coding สำหรับงานวิเคราะห์ข้อมูล" ข้อมูลร้านสมมติ ปีงบ 1 ต.ค. 2568 – 30 ก.ย. 2569

หน้าเว็บ React ไฟล์เดียว ผู้ใช้อัปโหลด `orders.csv` เอง ไม่ฝังข้อมูลในโค้ด และอ่านในเครื่องด้วย PapaParse

## นิยาม

- **ยอดขายสุทธิ** = qty × unit_price × (1 − discount_pct/100) เฉพาะ status = "จัดส่งสำเร็จ" ไม่รวม shipping_fee
- **กำไรขั้นต้น** = ยอดขายสุทธิ − qty × unit_cost (unit_cost จาก `products.csv`)
- **AOV** = ยอดขายสุทธิ ÷ จำนวนคำสั่งซื้อที่จัดส่งสำเร็จ
- **อัตรายกเลิก / อัตราคืนสินค้า** = แถวสถานะนั้น ÷ ทุกแถวในตัวกรอง × 100

## มีอะไรบ้าง

- การ์ด KPI 5 ใบ (เทียบเดือนก่อน + เส้นแนวโน้ม) กราฟเส้นรายเดือน กราฟตามช่องทาง กราฟแท่งแนวตั้งตามบริษัทขนส่งแยกหมวดสินค้า แผนที่จุดประเทศไทยแสดงยอดขายตามจังหวัด และจังหวัดอันดับต้นของแต่ละภูมิภาค
- ตัวกรองภูมิภาค หมวดสินค้า และเดือน มีผลกับทุกส่วน
- แท็บ **วันเมกะเซล** (10.10, 11.11, 12.12, 3.3, 6.6, 9.9) เทียบกับวันปกติ ต้องอัปโหลด `products.csv` เพิ่มเพื่อคำนวณกำไรขั้นต้น
- แท็บ **บทสรุปผู้บริหาร** ให้ Claude เขียนสรุปและรายงาน PDF จากตัวเลขสรุปไม่เกิน 30 ค่า ไม่ส่งข้อมูลดิบ แล้วตรวจว่าทุกตัวเลขในข้อความมีอยู่ใน JSON

## ไฟล์

- `index.html` หน้าเว็บทั้งหมด
- `thai-map.js` รูปร่างจังหวัด 77 จังหวัดสำหรับแผนที่ (ดูเครดิตด้านล่าง)
- `thai-font.js` ฟอนต์ IBM Plex Sans Thai (SIL Open Font License 1.1) ฝังเป็น base64 เพื่อให้ข้อความใน PDF เลือกและคัดลอกได้

## หมายเหตุ

ปุ่มสรุปให้ผู้บริหารและการดาวน์โหลด PDF ใช้ความสามารถของ claude.ai (`sample`, `downloads`) จึงทำงานเมื่อเปิดหน้านี้เป็น Artifact บน claude.ai เท่านั้น ส่วนอื่นเปิดจากไฟล์ได้ตามปกติ ไฟล์ CSV ไม่ได้อยู่ใน repo นี้ ใช้จากชุดผู้เรียนของคาบ
